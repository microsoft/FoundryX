# Support

For questions, bugs or feature requests, search the
[GitHub issues](https://github.com/microsoft/FoundryX/issues) before opening
a new issue.

Include your operating system, Copilot host and version, plugin version, FoundryX
CLI version, reproduction steps and expected behavior. Remove credentials, tokens,
tenant details and customer content from logs or screenshots.

The [README](README.md) covers installation and prerequisites. FoundryX CLI binaries
are published in [FoundryX releases](https://github.com/microsoft/FoundryX/releases?q=FoundryX&expanded=true);
the plugin does not bundle or automatically install the CLI.

Report security vulnerabilities through [SECURITY.md](SECURITY.md), not public
issues.

## Microsoft Support Policy

Support for this preview plugin is limited to the resources listed above.
